## 3. PDF 변환

**Markdown → PDF.** HTML·워드 조판을 하지 않는다 (`D-22`).

- 저장소 문서가 이미 Markdown이라 **변환만 하면 제출물과 저장소가 자동으로 일치**한다
- 도구: Pandoc 또는 VSCode Markdown PDF
- ⚠️ **D+7에 변환 테스트를 한 번 한다** — 표·이모지·한글 폰트가 깨지는지 미리 본다. D+9에 발견하면 늦다
