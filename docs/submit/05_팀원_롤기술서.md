## 3. 협업·분업 방식 🔴 요강 필수 (해당 시)

### 3.1 비동기 문서 교환

**같은 시간대에 붙어 있지 않아도 되게 설계했다.**

```
NulMa     → 배경 + 결정목록(추천안 포함)  → verpivia-1
verpivia-1 → 확정본                       → NulMa
NulMa     → 대조 + 질문                   → verpivia-1
verpivia-1 → 답변                         → NulMa      (×3 왕복)
```

**각 왕복이 문서로 남아 있다** (`docs/15_A트랙_대조.md`, `temp/`).
구두 합의가 아니라 **대조 가능한 기록**이고, 그래서 *"그때 그렇게 말했다"* 가 생기지 않는다.

> ★ **추천안을 붙여 보낸 게 핵심이다.** 빈 질문지를 보내면 상대가 처음부터 생각해야 하지만,
> 추천안이 있으면 **동의하거나 뒤집거나** 둘 중 하나다 — 그리고 **6건이 뒤집혔다.**
> 뒤집힘이 기록으로 남는 것도 이 형식 덕분이다.

### 3.2 파일 소유권 분리 — 기능이 아니라 디렉토리로

| 소유 | 경로 |
|---|---|
| `NulMa` | `core/` `core.tests/` `sim/` `sim.tests/` `tune/` `.github/` `docs/` |
| `verpivia-1` | `unity/` `data/encounters.json` · 아트 · 영상 |

**2인이 같은 파일을 만지면 `main` 직선 커밋(PR 없음)이 깨진다.** 그래서 기능이 아니라 경로로 갈랐다.

**경계면은 `Events/` 이벤트 로그 포맷 하나뿐이다.**

```
core   : 전투를 계산하고 이벤트 로그만 뱉는다
unity  : 로그를 재생만 한다 — 되감기·배속도 가능하다
sim    : 로그를 아예 끄고 돌린다 (처리량)
```

> ★ **팀원은 전투 코어 내부를 몰라도 Unity 를 만들 수 있다.**
> 그리고 이 경계가 지켜지면 **연출이 전투 시간에 영향을 못 준다** —
> 그게 깨지면 `sim` 과 Unity 결과가 갈라지고 **밸런스 검증 전체가 무너진다.**

**포맷을 D+2 에 v1 으로 동결했고, D+3 2회차에 한 항목(`Dodge`)이 늘었다.**
**맨 뒤에 붙여 기존 번호는 하나도 안 밀렸고**, 계약 테스트가 그 사실을 검사한다 —
*"동결"* 이 지키려던 게 *"늘리지 않는다"* 가 아니라 **"기존 번호를 안 민다"** 였기 때문이다.

### 3.3 경계를 실제로 지킨 기록 ★

**나눈 경계를 지킨 증거가 있어야 *"역할을 나눴다"* 가 주장이 아니게 된다.**

| 사례 | 무슨 일이 있었나 |
|---|---|
| `D-50` 적도 이동하는가 | AI 가 **추천안까지 만들었지만** 팀원에게 되돌려 보냈다 — 전투 감각은 A 트랙의 것 |
| `D-52` 사망 유닛 처리 | 같음. **우리 제안이 기각됐고** 팀원 판단이 채택됐다 |
| `D-73` `C2-B` 파동 | 데이터와 텍스트가 달랐지만 **AI 가 고치지 않고 미결로 등록했다** — 구조 수정은 저작 판단이다 |
| `skillPower` 의미 | 데이터가 규칙을 강제했지만 **게임 감각 영역이라 팀원 확인 안건으로 올렸다** |

> ★ **`D-73` 이 특히 그렇다.** AI 는 그게 밸런스를 망가뜨리고 있다는 걸 **실측으로 알고 있었다**
> (`C2` 출전률 91.6%, 목표 20~80%). 그런데도 **고치지 않고 사람에게 올렸고**,
> 사람이 결정한 뒤에야 **`[H]` 커밋으로 분리해서** 넣었다.
>
> 그 한 줄이 클리어율을 48% → 33.4% 로 옮겼다 — **최적화기가 할 수 없는 수정**이었기 때문이다.
