## 3. 협업·분업 방식 🔴 요강 필수 (해당 시)

### 3.1 비동기 문서 교환

`TBD` — 소스: `20` §3.1

```
사용자 → 배경 + 결정목록(추천안 포함)  → 팀원
팀원   → 확정본                        → 사용자
사용자 → 대조 + 질문                    → 팀원
팀원   → 답변                          → 사용자   (×3 왕복)
```

**각 왕복이 문서로 남아 있다.** 구두 합의가 아니라 **대조 가능한 기록**이다.
