### A1 라이선스 확인 기록

- 팩 내 `LICENSE.txt` 에 **CC0 1.0 Universal 전문**이 동봉되어 있음 (2026-07-31 원문 확인)
- 배포 페이지 문구: *"You can use any and all of the assets found in this package in your own games, even commercial ones. **Attribution is not required but appreciated.**"*

| 확인 항목 | 결과 |
|---|---|
| ① CC0 여부 | ✅ CC0 1.0 Universal |
| ② 상업적 이용 | ✅ 가능 |
| ③ **공개 저장소 포함·재배포** | ✅ 가능 (CC0는 재배포 제한이 없음) |
| ④ 출처 표기 의무 | ❌ 없음 (**단 본 문서에 자발적으로 명시**) |

> ③이 이 프로젝트에서 특히 중요하다. 요강이 **"게임 전체 소스 코드를 동일 저장소에 포함, public 권장"** 을 요구하므로
> 에셋이 공개 저장소에 그대로 올라간다. **"재배포 금지" 조항이 있는 팩은 이 지점에서 위험**하다.
> CC0는 이 문제가 원천적으로 없다. 이것이 A1을 채택한 결정적 이유다.

**표기 의무가 없어도 기재하는 이유:** 약관 제4조 1항이 활용 내역 고지를 의무화했고, 심사자 입장에서 출처가 투명한 편이 신뢰도가 높다.

### A2 라이선스 확인 기록

- GitHub 저장소 `packages/pretendard/dist/LICENSE.txt` 에 **SIL Open Font License 1.1 전문**이 동봉되어 있음 (2026-08-05 원문 확인)
- OFL은 폰트를 다른 소프트웨어와 함께 번들·배포·수정하는 것을 허용하는 라이선스

| 확인 항목 | 결과 |
|---|---|
| ① OFL 1.1 여부 | ✅ |
| ② 상업적 이용 | ✅ 가능 |
| ③ **공개 저장소 포함·재배포** | ✅ 가능 (OFL은 번들 배포 허용) |
| ④ 출처 표기 의무 | ❌ 폰트 자체 재판매만 제한, 게임에 번들하는 데는 표기 의무 없음 (본 문서에 자발적으로 명시) |

> (확인: Unity 가 생성한 csproj 목록에 `DomoNinja.Core.Tests` 가 없다. `Core` 와 `Unity` 둘뿐이다.)
>
> **NUnit 을 3.x 로 고정한 판단 자체는 유효하다** — UTF 가 NUnit 3 계열이라, 나중에 공유하려 할 때
> 4.x 였으면 Assert 문법 차이로 소스를 못 옮긴다. **선택은 맞았고 서술이 앞서 나갔다.**
>
> → 실제로 공유하려면 테스트를 `core/Tests/` (패키지 안)로 옮기고 `manifest.json` 의 `testables` 에
> `com.domoninja.core` 를 등록해야 한다. **Unity 테스트 통합은 P5 작업이므로 그때 처리한다** (`19` §6.6).
> 지금은 **`dotnet test` 단독**이고, 결정론 회귀는 CI 에서 그것으로 검증된다.

### 3.4 자체 구현 (외부 코드 차용 없음)

전투 코어 · 헤드리스 시뮬레이터 · **밸런스 목적함수** · **지배 빌드 지표(`M4a`/`M4b`)** · 커밋 규약 CI 검증 — **전부 직접 작성한다.**

> 근거: 약관 **제4조 2항** — "출품작은 참가자 **본인의 순수 창작물**이어야 하며…"
> 오픈소스 오토배틀러 코드 베이스가 다수 존재하지만 **차용하지 않는다** (`13_외부도구_조사.md` §2.3).

> ⚠️ **§3.3의 O7~O9와 경계가 헷갈릴 수 있어 명시한다.**
> **탐색 알고리즘은 가져다 쓰고(O7~O9), 무엇을 최적화할지는 직접 정의한다(§3.4).**
> 표준 수치 도구를 쓰는 것은 컴파일러를 쓰는 것과 같고, 약관 제4조 2항이 겨냥한 "게임 코드 베이스 차용"과 성격이 다르다.
> **밸런스 최적화기를 통째로 직접 짜겠다던 초기 계획은 `17` §8에서 철회했다** — 재발명에 쓸 시간을 목적함수 설계로 옮겼다.

## 4. 참고 문헌 (코드 차용 없음, 설계 근거로만 인용)

| R5 | Morris, Elementary Effects (SALib 구현) | 탐색 대상 파라미터 선정 |

> **R2는 인용 방식에 주의한다.** α-Rank를 "썼다"고 쓰면 사실과 다르다.
> **PvE라 적용 조건이 안 맞는다는 것까지 포함해** 기술 문서에 서술한다 — 한계를 밝히는 쪽이 신뢰도가 높다.
