# 제출물 ③ 게임 소개 및 설명 문서

---

## 1. 게임 제목 및 한 줄 소개

**제목**
Domo Ninja-desu

**한 줄 소개**
'선택과 집중'을 이용한 자신만의 빌드로 스테이지를 돌파하는 2D오토배틀러 게임

---

## 2. 게임 방법

### 2.1 목표

스테이지 하나당 8개의 라운드 구성. 7개의 일반 라운드와 1개의 보스 라운드 구성.
8라운드를 완주하면 승리. 선택한 캐릭터의 HP가 전부 소진되면 스테이지 패배.

### 2.2 게임 흐름(반복루프)

```
메인화면 - 스테이지 확인 후 선택
  ↓
스테이지 클릭시 - 로스터 선택 화면 전환
  ↓
로스터 6명 중 3명 선택 (런 시작 시 1회)
  ↓
[라운드] 상점 → 구매/보류 → 적 배치 공개 → 배치 조정 → 자동 전투 → 승패 → 재화·회복
  ↓  ×8(촤대 횟수)
종료 - 메인화면 이동
  
해당 루프를 반복하여 플레이

```

### 2.3 핵심 메커닉 — 선택과 집중

캐릭터마다 2개의 메인 스킬을 가진다. => 해당 스킬들은 캐릭터의 방향성을 결정하는 핵심요소
플레이어는 라운드를 클리어하면 받는 재화를 이용하여, 상점에서 스킬을 구매하여, 해당 스테이지 진행동안, 캐릭터를 임시 강화 할 수 있다.
상점에는 출전한 3명의 스킬만 등장하며, 각 캐릭터별 메인 스킬은 하나만 구매할 수 있다.
원하는 스킬이 나오지 않았다면, 리롤 기능을 이용하여 다른 스킬이 나오는 것을 기대하거나, 아이템을 구매하여 캐릭터를 강화 할 수 있다.
메인 스킬을 선택하면, 해당 메인스킬을 강화하는 보조스킬이 등장하며, 이를 이용하여 스테이지를 클리어 하는 것이 목표이다.

### 2.4 전투중 조작

캐릭터 배치와 상점 구매만 플레이어가 조작한다
배치 - 드래그앤드롭을 이용하여 원하는 위치에 배치한다.
상점 - 스킬/아이템 클릭 이후, 구매 버튼을 눌러서 구매. 아이템은 판매 가능하며, 판매기능 또한 동일하게 동작한다.
**전투 자체는 전부 자동으로 진행된다.** 전투 중 별도 조작·아이템 사용은 없다.

### 2.5 종료 조건

- 8라운드 완주 → 승리
- 선택한 캐릭터의 HP가 전부 0이 됨 → 패배
- 제한시간 초과 시 점증 디버프로 인한 전멸 → 패배
- 퇴각 기능을 이용하여, 스테이지를 클리어하지 못하더라도, 중간에 탈출 가능.

### 2.6 성장 요소

런 안에서는 스킬 강화(1→2→3단계) · 보조 스킬 · 아이템으로 성장한다.
런과 런 사이에는 메인 메뉴에서 전 캐릭터 공용 스탯(공격 · 체력 · 공속 · 기동 · 회복 · 재화)을 영구 강화할 수 있다.
