## 5. T2 즉시 착수용 — 스킬 작성 템플릿

**스키마 커밋을 기다리지 말고 이 형식으로 초안을 잡아도 된다.** (`08` §3 기준)

**템플릿 5종**

| 템플릿 | 파라미터 |
|---|---|
| `stat_mult` | 대상(self / allies / same_tag), 스탯, 배율 |
| `targeting` | 우선순위(nearest / lowest_hp / backline_first) |
| `conditional` | 트리거(hp_below / on_kill / every_n_sec) + 참조 효과 |
| `aoe` | 범위, 배율 |
| `status` | 종류(slow / armor_break / regen), 수치, 지속 |

**작성 단위: 캐릭터 6명 × 스킬 2개 = 12개.** 각 스킬에 3단계 강화 수치.

```json
{
  "id": "C2-B",
  "character": "C2",
  "template": "conditional",
  "trigger": { "type": "hp_below", "value": 0.5 },
  "effect": { "template": "stat_mult", "stat": "attack", "value": 1.6 },
  "tags": ["aggressive"],
  "upgrades": [
    { "level": 1, "value": 1.8 },
    { "level": 2, "value": 2.0 },
    { "level": 3, "value": 2.3 }
  ]
}
```

**작성 시 지켜야 할 것**

- **한 캐릭터의 스킬 2개는 성격이 갈려야 한다** — 지표 `M3b`(2택 선택 비율 20~80%)가 이걸 검증한다. 한쪽이 명백히 우월하면 그건 **함정 선택지**다
- **수치는 대충 잡아도 된다.** 시뮬이 고친다. 중요한 건 **구조와 성격의 차별화**
- 태그는 3종. 같은 태그 2개=소보너스 / 3개=대보너스 (`08` §5.2)

## 6. 커밋 규칙 요약 (양쪽 공통)

`09_커밋_규약.md` 전문 준수. 최소한 이것만은:

```
[AI] feat(core): 전투 틱 루프 구현        ← AI 생성, 사람은 승인만
[H]  fix(core): 타겟팅 순서 의존 제거      ← 사람이 직접 작성·교정
[BAL] data(data): 속성2 보너스 18→14      ← 시뮬 근거 밸런스 패치
[REV] revert: 위 패치 되돌림              ← 되돌림

의도: <왜 그렇게 지시/판단했는가>   ← 전 커밋 필수
```

- **AI 생성분과 사람 수정분은 반드시 분리 커밋** — 합치면 "AI가 뭘 못했는지"가 영구히 사라진다
- squash / force push 금지
- `[H]` 커밋에는 `Co-Authored-By` 를 붙이지 않는다
