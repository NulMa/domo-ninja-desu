## 1. 이 안의 결정적 장점 — 빌드 공간이 유한하고 전수 탐색이 가능하다 ★

### 1.1 공간 크기

| 축 | 경우의 수 |
|---|---|
| 로스터 6명 중 4명 선택 | C(6,4) = **15** |
| 출전 4명 각각 스킬 2택 | 2⁴ = **16** |
| **핵심 빌드 조합** | **240** |

미활성(스킬을 안 사는 선택)까지 포함해도 3⁴ × 15 = **1,215**.

### 1.2 왜 이게 중요한가

`08` §5의 **M4(지배 조합 점유율)** 는 이 프로젝트에서 가장 중요한 지표다. "적이 고정이면 정답이 하나 아니냐"는 반론에 숫자로 답하는 장치이기 때문이다.

- **기존 `08` 스펙**(상점에서 12종 중 5개를 랜덤으로 획득): 빌드 공간이 크고 랜덤 의존이라 **통계적 추정**만 가능했다. "1만 판 돌려보니 이 조합이 많더라" 수준
- **팀원 안**: 빌드 공간이 240~1,215로 유한하다. → **전수 탐색이 가능하다.** 모든 빌드를 각각 N회 시뮬해서 클리어율을 직접 구할 수 있다

**즉 M4가 추정치가 아니라 정확값이 된다.**

> 기술 문서에 쓸 문장이 달라진다.
> "샘플링 결과 특정 조합이 우세한 경향을 보였다" → **"가능한 240개 빌드를 전수 시뮬한 결과, 클리어 가능 빌드가 N개이며 최상위 빌드의 점유율은 X%다"**
> 후자는 **주장이 아니라 사실**이다. 이 대회에서 그 차이는 크다.

### 1.3 부수 이득 — 아트 물량

| | 기존 `08` | 팀원 안 |
|---|---|---|
| 유닛 아트 | **12종** | **6종** |
| 추가 자산 | — | 스킬 아이콘 12개 (아트 난이도 훨씬 낮음) |

`05` §3.2의 아트 물량 리스크에 대한 실질적 해법이다. 유닛 스프라이트 12종보다 유닛 6종 + 아이콘 12개가 훨씬 싸고, "다 똑같이 생긴 게임" 위험도 줄어든다.

### 1.4 배타성 규칙 자체의 값

> "선택받지 못한 스킬은 그 런 동안 다시는 상점에 등장하지 않는다"

- **되돌릴 수 없는 선택**은 로그라이크 재미의 핵심이고, 설명이 한 문장이면 끝난다 (심사자 온보딩에 유리)
- 60초 영상에서 **"스킬 선택 → 전투가 눈에 띄게 달라짐"** 이 읽히기 쉽다. 기존 스펙의 "유닛을 더 샀다"보다 시각적으로 명확하다
- 팀원의 뉴럴클라우드 역기획("고정 전력 + 런 단위 랜덤 강화")과 일관된 설계다. 리서치가 설계로 이어진 흔적이라 문서에도 쓸 수 있다

## 2. 최대 리스크 — 스킬 12개는 코드 12개다 ★

**이게 유일한 심각한 문제다.**

- 기존 `08`의 유닛 12종은 **스탯 차이만 있으면 됐다** (`hp`/`attack`/`range`). 데이터 12줄이다
- 팀원 안의 스킬 12개는 **각각 고유한 동작**을 요구한다. 12개의 개별 구현이고, 각각 전투 루프에 개입한다
- 10일 일정에서 이건 실제로 무겁다. 게다가 **결정론(`05` §2.4)을 12곳에서 각각 지켜야 한다**

### 해법: 스킬을 "고유 로직"이 아니라 "효과 템플릿 + 파라미터"로 설계한다

효과 템플릿을 **4~6종**만 만들고, 12개 스킬은 그 조합·수치 차이로 표현한다.

예시 템플릿:

| 템플릿 | 파라미터 |
|---|---|
| 스탯 배율 | 대상(자신/아군전체/같은태그), 스탯, 배율 |
| 타겟팅 변경 | 우선순위 규칙(최근접/최저HP/후열우선) |
| 조건부 발동 | 트리거(HP 임계/처치/N초마다), 효과 참조 |
| 광역화 | 범위, 배율 |
| 지속효과 부여 | 종류(둔화/방깎/재생), 수치, 지속 |

```json
{ "id": "S03", "template": "conditional",
  "trigger": { "type": "hp_below", "value": 0.5 },
  "effect": { "template": "stat_mult", "stat": "attack", "value": 1.6 },
  "tags": ["aggressive"] }
```

**얻는 것 3가지**

1. 구현이 12개가 아니라 **템플릿 5개**로 줄어든다. 결정론도 5곳만 지키면 된다
2. 스킬이 **데이터가 된다** → `08` §6의 "코드에 상수를 박지 않는다" 원칙이 스킬까지 확장된다. **AI가 밸런스 패치할 표면이 넓어진다** — edge 축에 직접 이득
3. 밸런스 조정 시 스킬 수치를 JSON에서 바꾸면 끝. 재컴파일 불필요

> **이 조건이 붙지 않으면 채택을 권하지 않는다.** 고유 로직 12개는 D+5~6 판정에서 게임이 안 굴러가는 가장 흔한 경로다.

## 3. 반드시 명확히 해야 할 것 — 랜덤성의 출처 ★

**제안 명세에 상점 재고의 무작위성이 언급되지 않았다. 이게 비면 게임이 1회용이 된다.**

현재 구조를 그대로 읽으면:

- 적 관문 = 고정 (`D-08`)
- 로스터 = 고정 6명
- 스킬 = 캐릭터당 2택, 상점에서 구매

→ **랜덤 요소가 하나도 없다.** 그러면 첫 런에서 최적해를 찾는 순간 게임이 끝난다. 심사자가 두 번 플레이할 이유가 없어진다.

**해결안: 상점 재고를 매 라운드 무작위 부분집합으로 제한한다.**

- 매 라운드 상점에 전체 품목 중 **K개만** 등장 (예: 4개)
- 원하는 스킬이 언제 나올지 모른다 → "지금 나온 걸 살까, 재화를 아껴서 기다릴까"라는 긴장이 생긴다
- 배타성 규칙과 맞물려 **"기다렸는데 안 나왔다"** 는 상황이 발생 → 로그라이크의 좋은 압박

시뮬 관점에서도 이게 낫다: **목표 빌드 × 상점 시드**로 돌리면 "이 빌드가 얼마나 안정적으로 도달 가능한가"까지 측정된다.

## 4. `08` 스펙에서 대체·폐기되는 항목

| `08` 항목 | 처리 | 사유 |
|---|---|---|
| §2.2 유닛 12종 (속성4×역할3) | **6종으로 축소** | 로스터가 6명 |
| §2.4 3개→2성 합성 | **폐기** | 로스터 고정이면 같은 유닛이 중복 획득되지 않는다 |
| §4.2 레벨·경험치 | **폐기** | 출전 4명 고정이면 배치 슬롯 확장이 없다 |
| §5 M6 (Lv5 도달 분포) | **폐기 → 대체** | XP 소멸. **"스킬 4개 활성화 완료 라운드 분포"** 로 대체 |
| §3 시너지 2축 | **스킬 태그 기반으로 이동** | 별도 시스템을 두지 말고 스킬 데이터의 `tags` 로 처리. 축이 둘이면 3~5분 게임에 과하다 |
| §5 M3 (유닛 등장률) | **스킬 채택률로 변경** | 12개 스킬 각각 5~80% 구간 유지 |
| §4.1 경제 | **재설계** | 리롤의 의미가 달라진다 (§5 미결) |

**유지되는 것:** 라운드제 PvE(`D-08`), 8라운드/생명 3, 전열·후열 배치, 결정론, 데이터 주도 원칙, M1·M2·M4·M5.

> 폐기 항목이 적지 않지만 **대부분 "단순화"** 다. 합성·레벨·시너지 시스템 3개가 빠지고 스킬 시스템 1개가 들어온다.
> 순 구현량은 오히려 **줄어들 가능성이 높다** — 단 §2의 템플릿 조건이 지켜질 때만.

## 6. 권고 정리

**채택하되, 아래 3개를 조건으로 건다.**

1. **스킬 = 템플릿 + 파라미터** (고유 로직 12개 금지) — §2
2. **상점 재고 무작위화** — §3
3. 시너지·합성·레벨 3개 시스템 **폐기** (스킬로 통합) — §4

이 조건이 충족되면, 이 안은 기존 `08` 스펙보다 **아트가 싸고, 설명이 쉽고, 무엇보다 M4를 전수 탐색으로 정확히 계산할 수 있다.**
마지막 항목이 이 프로젝트의 edge 축에 직접 기여하므로, 그것만으로도 갈아탈 이유가 된다.
