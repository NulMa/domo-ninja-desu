# 🅰 전투 엔진 규칙 — 최종 확정 (10건)

> `00_먼저읽기_배경.md`, `01_A_전투엔진_결정목록.md` 논의 결과 확정본.
> 이대로 `08_게임_스펙.md` 「전투 시스템」 절에 반영.

| # | 항목 | 최종 결정 |
|---|---|---|
| **A-1** | 이동 | **있음.** 정수 좌표 그리드 위 그리디 1스텝 이동 — 목표까지 dx/dy 중 **차이가 큰 축을 우선 축소**. 동률이면 **x축 우선**(고정)으로 이동. 보드 크기 **4×6** 확정 |
| **A-2** | 시간 모델 | 고정 틱 20/sec + 정수 누적 |
| **A-3** | 배치/사거리 | 전열·후열 구분 없음(자유 배치). 거리 판정·정렬은 **정수 제곱 거리**로 처리(sqrt는 비교에 쓰지 않음, 표시용에만 필요시 계산) |
| **A-4** | 타겟팅 | 기본 최근접 우선, 동률시 슬롯 인덱스 오름차순. 예외: ①일부 스킬 지정 타겟팅 ②몬스터 무적 상태 |
| | 틱당 처리 순서 | 매 틱 **슬롯 인덱스 오름차순** 고정 순회. 유닛별로 **이동판정 → 공격판정** 순차 처리. 이동 목표 칸이 겹치면 **먼저 처리된 유닛이 점유**, 나중 유닛은 그 틱은 정지 |
| **A-5** | 종료조건 | 전멸 시 종료. 라운드 제한시간(임시 45초) 초과 시 아군에게 디버프 |
| | 디버프 수치 | 시작값 유지, **30초(600틱)에 걸쳐 선형 증가**하도록 변경.<br>공식: `value_permille(t) = start_permille + (max_permille - start_permille) * min(t,600) / 600` (정수 나눗셈, t=디버프 발동 후 경과 틱)<br>**회복량 감소**: 50% → 100% (30초 도달, 이후 클램프)<br>**고정 데미지**(최대체력 %, 매틱 적용): 1% → **30%(상한)** (30초 도달, 이후 클램프) |
| **A-6** | 라운드간 HP | HP 잔존(누적), 완전회복 없음 |
| | 사망 유닛 | 스테이지 종료까지 부활 없음 |
| **A-7** | 스킬 발동 | 기본 주기 트리거(쿨다운). 보조 선택 스킬은 상시 패시브 |
| | 쿨다운 처리 | ⚠️ **구현 주의**: 스펙 표기는 "N초"라도 내부 저장·판정은 틱 수(N×20) 정수로 변환해서 처리할 것. 초 단위 float 누적 금지 |
| **A-8** | 개입 지점 | 배치, 라운드 종료 후 상점. 그 외 전투는 전부 오토 |
| **A-9** | 연출-로직 분리 | 연출은 로직에 영향 없음. 코어는 이벤트 로그만 출력, Unity는 재생만 |
| **A-10** | 아이템 | 4종(캐릭터 지정 / 전체 / 직군 / 조건부) 버프. **중첩 연산은 전부 합연산**(퍼센트 버프는 전부 더한 뒤 마지막에 한 번 곱 적용) |

## 남아있는 열린 값 (구현 중 확정 필요)

- **A-5**: 라운드 제한시간 정확한 초(현재 임시 45초)는 밸런스 시뮬 돌리면서 조정 예정.
- **A-1**: 이동 동률 시 x축 우선으로 반영. y축 우선(세로 이동 우선)을 원하면 변경 필요.
