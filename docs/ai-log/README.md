# AI 지시 아카이브 (`D-05`)

확정: 2026-08-01 (D+1)

> **이 폴더는 제출물 ④ AI 활용 기술 문서 3장의 원자료다.**
> 요강이 요구하는 것: *"AI 대상 **주요 프롬프트 및 지시 사항**"*.
> 문서 3.2는 **실제 사용한 지시문을 원문 인용**해야 하는데, **그때 가서 복원할 수 없다.**

---

## 왜 파일로 남기는가

| 안 | 판정 |
|---|---|
| 로컬에만 보관하고 나중에 발췌 | ❌ **사후 가공으로 보인다.** 이 대회가 가장 싫어할 형태 |
| 커밋 본문에만 인용 | △ 노이즈는 없지만 선별 기준을 따로 설명해야 한다 |
| **`docs/ai-log/` 파일 + 핵심은 커밋 본문에도** | ✅ **채택** |

> **이 대회는 과정을 증거로 보겠다는 대회다. 커밋 노이즈보다 증거 부재가 훨씬 큰 손해다.**
> 파일로 남기면 심사자가 직접 열어볼 수 있고, 커밋 본문에도 인용하면 **`git log` 만 훑어도 드러난다.**

---

## 파일 규칙

```
docs/ai-log/
  README.md              ← 이 문서
  2026-08-01_D+1_A트랙반영.md
  2026-08-01_D+1_최적화조사.md
  …
```

**파일명**: `YYYY-MM-DD_D+n_주제.md` — 날짜순 정렬되고 어느 단계였는지가 파일명에서 읽힌다.

## 파일 형식

```markdown
# <주제>

일자: 2026-08-0X (D+n)
관련 결정: D-XX / 관련 커밋: <해시>

## 맥락
왜 이 지시를 했는가. 직전에 무엇이 막혀 있었는가.

## 지시 원문
> (붙여넣기. 다듬지 않는다)

## 결과
무엇이 나왔는가.

## 사람의 개입
- 받아들인 것:
- 되돌린 것 / 고친 것:
- **왜 그렇게 판단했는가:**   ← ★ 문서 4장의 핵심 재료
```

---

## 원칙 4가지

1. **다듬지 않는다.** 오타·반말·중간에 끊긴 지시 그대로. 정제하면 사후 가공이 된다
2. **실패한 지시를 반드시 남긴다.** 문서 3.3이 *"실패한 지시와 그 수정 과정"* 을 요구한다.
   성공만 나열하면 프로세스 설계가 아니라 **운으로 읽힌다**
3. **판단 근거를 적는다.** "고쳤다"가 아니라 **"왜 그게 틀렸다고 봤는가"**.
   AI 산출물을 받아들일지 말지를 무엇으로 갈랐는지가 이 대회가 보는 것이다
4. **비밀정보 금지.** API 키·개인정보·팀원 사적 대화는 넣지 않는다. 공개 저장소에 그대로 올라간다

## 커밋 규약 연동 (`09_커밋_규약.md`)

- 아카이브 파일 커밋은 `[H] docs(ai-log): …` 형태
- **결정적인 지시는 해당 작업 커밋 본문에도 인용한다.** 두 곳에 남는 게 의도다
- 커밋 본문 예:

```
[AI] feat(core): 전투 틱 루프와 이동 판정 구현

의도: A-1 그리디 1스텝을 슬롯 인덱스 오름차순으로 고정 순회하도록 지시.
      동률 시 x축 우선을 명시하지 않으면 순회 순서 의존이 생긴다.
지시: "매 틱 슬롯 인덱스 오름차순으로 이동→공격 순서로 처리하고,
      목표 칸이 겹치면 먼저 처리된 유닛이 점유하게 해줘"
검증: 같은 시드 2회 실행 결과 해시 동일
원문: docs/ai-log/2026-08-0X_D+n_전투코어.md
```

## ⚠️ 소급 기록 대상 (D+0~D+1)

**아카이브를 D+1에 시작했으므로 그 이전은 소급 기록이다.** 이 사실을 숨기지 않고 각 파일에 명시한다.

| 일자 | 내용 | 상태 |
|---|---|---|
| D+0 (07-31) | 대회 리서치 → 전략 분석 → 게임 컨셉(`D-30` 배타 선택) 확정 | ☐ 소급 |
| D+0 | 팀원 기획 대조, 스킬 노선안 검토, `08` v0.3~v0.4a | ☐ 소급 |
| D+1 (08-01) | A 트랙 확정본 대조 → 재질의 6건 → `08` v0.5 | ☐ 소급 |
| D+1 | 밸런스 최적화 방법론 조사 → `17` (판단 1건 뒤집힘) | ☐ 소급 |
| D+1 | 설계 감사 → 공백 8건 발견 | ☐ 소급 |
| D+2 이후 | — | **실시간 기록** |

> **소급분은 "이 시점에 이런 지시를 했다"가 아니라 "이 시점의 산출물과 판단은 이랬다"로 쓴다.**
> 원문이 남아 있지 않은 부분을 원문인 척하지 않는다. **없는 건 없다고 쓰는 게 낫다.**
> 실제로 `00_진행로그.md` 에 판단과 번복이 날짜별로 남아 있어 소급 재구성의 근거는 충분하다.
