## 3. 시상 및 채용 혜택

| 상 | 선정 규모 | 팀 상금 |
|---|---|---|
| 대상 | 1팀 | 5,000만 원 |
| 최우수상 | 1팀 | 2,000만 원 |
| 우수상 | 1팀 | 1,000만 원 |

상금 합계 8,000만 원. 사이트 표기 "총 3.5억 원"은 상금 + 채용 혜택(근속 보너스 등) 환산치다.

**수상자 특별 혜택**

- 수상자 **전원 최종 면접으로 직행** (채용 패스트트랙, 학생 포함)
- 최종 입사 시 **근속 보너스 최대 3,000만 원**
- 팀 상금은 채용 여부와 무관하게 지급
- 팀 상금은 팀대표자에게 일괄 지급, 팀원 간 배분은 팀 내부 합의 사항

> **원문 내 상충 사항 주의**
> 시상 섹션 주석: "상금에 대한 제세공과금은 **수상자 부담**입니다."
> FAQ: "제세공과금은 **NHN에서 원천징수 후 지급**합니다."
> 두 표현은 실무상 같은 의미(수상자가 부담하되 NHN이 원천징수)로 읽히지만, 문면은 어긋난다. 수상 시 운영진 확인 필요.

## 4. 사전 과제 (예선) — 제출물 5종

**사전 과제 주제 (사이트 명시): "AI를 활용한 게임 제작"**
→ 장르·소재에 대한 제한은 명시되어 있지 않다.


> **아래 5개 항목을 모두 제출해야 하며, 하나라도 누락 시 심사 대상에서 제외됩니다.**

### ① 플레이 가능한 빌드 및 소스 코드 (GitHub)

심사자가 직접 플레이할 수 있는 형태로 제출. 아래 중 하나 이상:

- **웹 빌드**: GitHub Pages 등으로 배포, 링크 클릭만으로 브라우저에서 바로 플레이
- **모바일 앱**: APK 파일 또는 테스트 배포 링크 (TestFlight, Google Play 내부 테스트 등)

제약 사항:

- 별도 유료 라이선스 없이 심사자가 실행할 수 있어야 함
- **보안상의 이유로 PC 실행 파일(.exe 등) 직접 제출 불가**
- 게임 전체 소스 코드를 동일 저장소에 포함, **커밋 기록 유지**
- 저장소 public 제출 권장. 부득이 비공개일 경우 심사 계정(`dl_gameai_reviewer@nhn.com`) 초대

### ② 플레이 동영상 (YouTube)

- **30~60초 분량**, **실제 게임 플레이 장면 중심**으로 제작
- **AI를 이용한 조작·합성이나 타인 영상의 도용 불가.** 실제 플레이 화면 그대로
- 공개 또는 일부 공개(링크 공유) 상태로 업로드

### ③ 게임 소개 및 설명 문서 (PDF)

포함 항목:

- 게임 제목 및 한 줄 소개
- 게임 방법: 목표 · 조작 · 종료 조건 포함
- 실행 방법: 설치 및 실행 방법
- 플레이 링크 또는 설치 방법 (웹 URL / APK · 테스트 링크)
- 플레이 영상 링크

### ④ AI 활용 기술 문서 (PDF) ★ 핵심

포함 항목 (원문):

- **AI 활용에 대한 기술적 설명 (예: 구조 설명, AI 대상 주요 프롬프트 및 지시 사항)**
- 외부 에셋 / 오픈소스 출처

> 해석: "AI 대상 주요 프롬프트 및 지시 사항"이 "외부 에셋 출처"와 병렬 배치된 구조.
> 인게임 NPC 프롬프트가 아니라 **제작 과정에서 AI에게 준 지시**를 의미한다.

### ⑤ 팀원 롤 기술서 (PDF)

- **2인 이상 팀인 경우에만 제출.** 개인 참여 시 생략
- 팀원별 이름 / 담당 역할 (기획 · 개발 · 아트 · AI 활용 등)
- 각 팀원이 실제로 맡아 구현한 영역
- (해당 시) 협업 · 분업 방식

## 5. 유의사항 (원문)

- 타인의 저작물·아이디어를 무단 도용한 경우, **발생하는 모든 책임은 제출자 본인에게 있으며 선발이 취소**될 수 있음
- 외부 에셋(이미지·사운드 등) 사용 시 출처와 라이선스를 **AI 활용 기술 문서에 반드시 명시**
- **AI 도구 사용은 허용·권장하나, 사용 도구와 활용 내역을 반드시 기재**해야 함
- 제출 링크(GitHub · YouTube)는 **심사 종료 시점까지 접근 가능한 상태로 유지**
- 접수 마감 후에는 제출 내용 변경 불가
- 개인정보 수집·이용 및 저작권 관련 동의가 제출에 포함됨

## 6. 본선 (48시간)

- **주제 공개와 동시에 48시간 개발**
- 제출물: **게임 프로토타입 + AI 에이전트 설계서 + 디렉팅 명세서**
- 발표·시연: 팀별 지정 시간 내 진행. 형식 자유 (PPT, 데모 시연 등)
- 노트북·계정·유료 API는 참가자 직접 준비. 행사장은 Wi-Fi·전원 등 기본 환경만 제공

## 7. 약관 주요 조항

### 제4조 (출품작의 제출)

- 출품작 개발에 사용한 **주요 AI 도구의 명칭과 활용 방식**을 주최사에 고지해야 함
- 출품작은 본인의 순수 창작물이어야 하며 타인의 저작권·상표권·특허권·영업비밀 미침해 보증
- 생성형 AI · 오픈소스 · 외부 API 활용 시 관련 라이선스 및 이용 조건 준수

### 제5조 (심사 및 수상)

- 심사는 주최사가 구성한 심사위원단이 진행
- **심사 기준·방식·수상 규모는 주최사 운영 계획에 따라 결정되며, 세부 평가 내용은 공개하지 않을 수 있음**

### 제6조 (저작권 귀속)

- 출품작의 저작권 및 지식재산권은 **원칙적으로 참가자에게 귀속**
- 단, 주최사는 **수상작에 한하여** 홍보·결과 발표·보도자료·사례집·아카이브 목적으로 **접수 시작일로부터 1년간 무상 이용** 가능

### 제7조 (수상작 우선협상권) ★ 전략적으로 중요

- 수상자는 주최사에 수상작의 **사업화·투자·퍼블리싱·공동개발**에 관한 우선협상권 부여
- 행사 기간: **대회 종료일로부터 4개월**
- 우선협상기간 동안 제3자와 계약·협상 전 주최사에 우선 협상 기회 부여 의무
- 단, 계약 체결 의무나 사업화 강제는 아님
- **채용 여부와 무관하게 적용**

> 해석: NHN이 수상작을 실제 상품화할 여지를 열어둔 조항.
> **본선에서는 사업성·확장 가능성도 평가축에 들어간다는 신호.**

### 제2조 2항 (재직자 참가)

- 타사 재직자·프리랜서·개인사업자 참가 가능
- 단, **소속사 사규·근로계약 위반 여부는 본인이 사전 확인**해야 하며, 신청 시 문제없음을 보증한 것으로 간주
- 출품작이 소속사의 직무발명·업무상저작물에 해당하지 않음을 보증

## 8. FAQ 요약

| 질문 | 답변 |
|---|---|
| 학생 참가 가능? | 가능 (만 19세 이상). 채용 패스트트랙도 대상 포함, 입사 시기 별도 조율 |
| 타사 재직자 참가 가능? | 가능. 사규 위반 여부는 본인 책임 |

| 유료 API 비용? | **참가자 본인 부담** |
| NHN 제공 인프라? | 행사장 Wi-Fi·전원 등 기본 환경만. 노트북·계정·API는 직접 준비 |
| 부분 참여 가능? | 48시간 전 일정 참여 원칙. 부득이 시 사전 협의 |
| 부정행위 적발 시? | 수상 취소 · 인재 풀 등록 제외 |
| 행사장 촬영? | 본인 작업물만 가능. 타 팀 작업물·심사 진행 촬영 금지 |
